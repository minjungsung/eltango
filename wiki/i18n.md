# 국제화 (i18n)

## 개요

엘땅고는 [next-intl](https://next-intl-docs.vercel.app/) v4를 사용하여 한국어(ko)와 영어(en) 두 가지 언어를 지원합니다.

## 지원 언어

| locale | 언어 | URL 예시 |
|--------|------|---------|
| `ko` | 한국어 (기본) | `/`, `/sns` |
| `en` | 영어 | `/en`, `/en/sns` |

기본 locale (`ko`)은 URL prefix가 생략됩니다 (`localePrefix: "as-needed"`).

## 설정 파일

### `i18n/routing.ts`

라우팅 설정을 정의합니다:

```typescript
import { defineRouting } from "next-intl/routing";

export const routing = defineRouting({
  locales: ["ko", "en"],
  defaultLocale: "ko",
  localePrefix: "as-needed",  // ko는 prefix 생략
  localeDetection: true,       // Accept-Language 헤더 감지
});

export type Locale = (typeof routing.locales)[number]; // "ko" | "en"
```

### `i18n/request.ts`

서버 사이드에서 요청별 locale과 메시지를 결정합니다:

```typescript
import { getRequestConfig } from "next-intl/server";
import { hasLocale } from "next-intl";
import { routing } from "./routing";

export default getRequestConfig(async ({ requestLocale }) => {
  const requested = await requestLocale;
  const locale = hasLocale(routing.locales, requested)
    ? requested
    : routing.defaultLocale;

  return {
    locale,
    messages: (await import(`../messages/${locale}.json`)).default,
  };
});
```

### `i18n/navigation.ts`

locale-aware 네비게이션 유틸리티를 생성합니다:

```typescript
import { createNavigation } from "next-intl/navigation";
import { routing } from "./routing";

export const { Link, redirect, usePathname, useRouter, getPathname } =
  createNavigation(routing);
```

## 컴포넌트에서 사용하기

### 클라이언트 컴포넌트

```typescript
"use client";
import { useTranslations } from "next-intl";

export function Hero() {
  const t = useTranslations("hero");
  return <h1>{t("titleEn")}</h1>;
}
```

### 서버 컴포넌트

```typescript
import { getTranslations } from "next-intl/server";

export async function generateMetadata({ params }) {
  const { locale } = await params;
  const t = await getTranslations({ locale, namespace: "metadata" });
  return { title: t("title") };
}
```

## 언어 전환 동작

1. 사용자가 `LanguageSwitcher` 버튼 클릭
2. `useRouter().replace(pathname, { locale: nextLocale })` 호출
3. `NEXT_LOCALE` 쿠키 설정 (1년 유효, 다음 방문 시 기억)
4. 같은 페이지의 다른 locale 버전으로 전환

## 새 언어 추가 방법

1. `i18n/routing.ts`에 locale 추가:
   ```typescript
   locales: ["ko", "en", "ja"],
   ```

2. `messages/ja.json` 생성하여 모든 키 번역

3. `app/[locale]/layout.tsx`의 `generateMetadata`에서 `alternates.languages`에 추가

4. `LanguageSwitcher` 컴포넌트 수정 (현재는 2개 언어 토글 방식)

## 규칙

- **하드코딩 금지** — JSX에 직접 한국어/영어 텍스트를 작성하지 않습니다
- **네임스페이스 분리** — 각 섹션/기능별로 네임스페이스를 분리합니다
- **키 일관성** — `ko.json`과 `en.json`의 키 구조는 동일해야 합니다
- **서버/클라이언트 구분** — 서버에서는 `getTranslations`, 클라이언트에서는 `useTranslations` 사용
